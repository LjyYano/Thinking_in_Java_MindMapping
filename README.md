## 关于这个仓库

这个仓库始于 2017 年整理《Java 编程思想》的思维导图，后来逐渐发展为个人知识库：包括 Java、Redis、Spring 等后端技术，AI / Agent 工程实践，以及读书、游戏和生活记录。

仓库沿用 `Thinking_in_Java_MindMapping` 这个历史名称；**Yano's Notes** 则是现在的内容入口。这里的旧文章代表写作时的认识，不保证适用于最新版本。遇到版本差异时，请以官方文档为准，也欢迎通过 Issue 指出问题。
